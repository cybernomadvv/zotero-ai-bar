从安装到提出第一个问题。这里介绍本改进版的实际使用方式和边界。

本项目基于 swcxito 的 Zotero AI Bar v1.6.10，属于独立改进版。沿用原插件 ID，安装会替换上游版本。请先备份 Zotero 配置。

01 / 安装插件

支持范围沿用上游 Zotero 7–10；本改进版主要在 Windows / Zotero 10 上进行运行验证。

下载 XPI 安装包 ↓

安装包由本仓库 GitHub Actions 从已提交源码构建。离线词典、翻译模型和 Python 不包含在 XPI 中。

  1. 下载 zotero-ai-bar.xpi，保留文件后缀，不要解压。
  2. 打开 Zotero，进入工具 → 插件 / 附加组件。不同 Zotero 版本的名称可能略有差异。
  3. 在齿轮菜单中选择从文件安装插件，选中刚下载的 XPI。
  4. 按 Zotero 提示完成安装或重启。在设置中找到 zotero AI bar。

升级前建议备份 Zotero 配置文件夹。此 fork 沿用 zaibar@fukeke.com，不能与上游版本同时启用。

02 / 连接你自己的模型

插件负责把问题和上下文发送给你选择的服务商；它本身不提供模型账号、API Key 或免费额度。

普通 API

  1. 在 设置 → zotero AI bar 中打开模型 / 服务商配置。
  2. 选择服务商，填写它提供的 API Key；使用自定义兼容服务时，填写对应 API 地址。
  3. 添加可用模型并启用，关闭设置后，在聊天输入栏选择它。

Magpie

先启动自己的 Magpie 实例。默认 API 地址为 http://127.0.0.1:3425/v1，填写该实例要求的 MAGPIE_API_KEY。

已配置 Magpie 后，启动插件、打开模型选择器或模型设置时会请求该实例的 /models。新增模型自动加入列表，当前选择和已有模型的关闭状态保留。服务不可用时保留已保存列表；恢复后再次打开选择器即可刷新。

模型用量按服务商条款计费。Magpie 的实际模型、权限和订阅取决于你的本机配置，不保证每个实例拥有相同模型。

实验性 Codex 订阅接入

需要受支持的本机运行时及符合条件的账号。插件不内置订阅或运行时。启用前阅读仓库中的 Codex 接入说明。

03 / 围绕文献提问

在阅读器中选中一段文字，使用划词工具栏解释、总结、翻译或输入问题。侧栏与独立聊天窗口均可使用。

模式适合的问题上下文方式
快捷这个概念是什么意思？围绕当前问题和选区，按设置附加附近内容。
全文这篇论文的核心方法是什么？附加当前文献正文；受模型上下文容量限制。
Agent找到方法的依据，再解释给我。使用工具按需搜索、读取文档或文库。

工具栏可以自定义直接显示的操作和顺序，至少保留三个，其余进入“更多”。引用或使用 AI 答案前，请回到原文核对。

04 / 翻译与离线资源

选区翻译浮层贴近阅读位置。已有全文缓存时，优先查询论文术语、选区修订及匹配的句子译文；可选的本地词典和英译中模型需单独准备。

只安装 XPI，不等于已配置离线翻译

离线资源包括 ECDICT 词典、OPUS-MT 英译中模型，以及独立 Python / CTranslate2 运行环境。模型不需要 GPU；当前支持范围是英译中，输出作为基础译文使用。

源码中的 scripts/prepare-offline-assets.py 用于准备资源，依赖见 scripts/local-translation-requirements.txt。部署辅助脚本包含本机 profile 路径，必须先按自己的环境修改，并退出 Zotero 后再运行。

完整步骤和资源来源见 本地优先翻译说明。未配置时，请使用已连接的模型服务，不要把 XPI 安装成功当作离线资源已就绪。

点击“重新翻译”会显式调用 AI。全文缓存完成后，重译仅修改对应选区或匹配句子的译文，不覆盖其他句子。

05 / 全文翻译，随时接着来

  1. 打开论文后，选择翻译此文章，后台逐批处理正文和术语。
  2. 每个完整批次校验通过后保存；运行中可使用暂停并保存。
  3. 发生中断后，界面显示已保存进度，点击继续全文翻译处理剩余内容。

例如一篇内容分为 9 段，前 4 段已保存，恢复时会跳过这 4 段。正在处理但尚未完成的批次会重新请求。

恢复前会校验原文及目标语言，避免混用不同内容的译文。只有全部处理完成并成功写盘，状态才变为 全文翻译：true。

缓存位于当前 Zotero profile 下的 zaibar/paper-translations/，其中包含论文正文和译文。详细边界见 断点保存说明。

06 / 常见问题

提示 API key not configured for magpie

检查 Magpie 服务商配置中的凭据是否已填写并保存。确认本机服务地址正确、实例正在运行；网站不会提供或读取你的密钥。

新加的 Magpie 模型没有出现

重新打开模型下拉框或模型设置，触发同步。确认模型确实由当前实例的 /models 返回，并检查模型是否被关闭。

输入中文时，候选窗在左上角闪一下

在当前测试环境中，微信输入法的候选窗首次定位可出现闪现，普通原生文本框也能复现。用户反馈微软拼音无此现象，可尝试切换输入法。这不是已解决的问题，插件回归通过不等于系统候选窗没有闪现。

没有响应或翻译失败

检查服务商状态、密钥、模型权限和余额。全文任务失败后保留已保存批次，可稍后继续；尚未完成时不会标记为完成。

在哪里反馈问题？

前往 本 fork 的 GitHub Issues，附上 Zotero 版本、操作系统、模型名称和复现步骤。请遮挡密钥及个人资料。

07 / 数据与隐私

云端问答会发送问题、选区，以及当前模式需要的正文或图片。全文问答和全文翻译可能发送整篇论文内容。请根据文献使用权限和服务商的数据条款决定是否启用。

离线词典与本地模型不需要云端翻译请求；显式的 AI 重译仍会调用所选服务。本网站是静态说明站，没有在线 AI、登录系统或文库访问功能，也没有接入统计脚本。托管平台可能按自身政策记录访问日志。
