# 本地优先翻译与自定义工具栏：已实现与验收

2026-11-17 已安装至日常 Zotero 10 profile，保留已有供应商及当前模型选择。

## 使用入口

设置 → AI 工具栏 → 划词工具栏功能排布：勾选直接显示的操作，使用上下按钮排序。至少保留三个直接显示的操作，未选操作自动进入“更多”。包含内置操作和用户自定义提示词，配置在下一次划词时生效。工具栏按内容宽度显示，过长时受阅读器视口限制并换行；翻译浮层使用同样的宽度。

打开论文时，文章侧栏及划词翻译框读取这篇附件、目标语言对应的状态。界面实时显示 `全文翻译：false/true`。

- 未决定：显示“翻译此文章／不翻译此文章”，当前选区同时查询本地资源，不被选择或后台任务阻塞。
- 同意全文翻译：后台逐句分批处理全文并提取术语；进度显示完成句数／总句数。译文和术语写盘成功之后才置 true。
- 拒绝全文翻译：记住选择，保留 false，默认走本地词典或本地小模型；角落保留“全文翻译”入口。
- 已完成：优先读取论文专属术语、局部修订和句子译文；句子必要时可让 AI 从已有源句中选择匹配，不由该匹配请求生成新译文。
- 同一篇论文从多个窗口启动时只产生一个全文任务。全文任务失败、缺失输出或中断不会将标志设成 true。

## 选区翻译的资源顺序

1. 有全文缓存时，先查询选区修订、论文术语和标准化后完全匹配的句子译文。
2. 单词／短语未命中时查询本地词典，包括常见词形回退。
3. 句子未精确命中且有相近源句时，可请求 AI 只选择已有条目 ID，然后显示该条目的已存译文。匹配服务失败仍继续本地回退。
4. 无可用本地条目时，调用轻量本地翻译模型生成基础译文。
5. 未做全文翻译、尚未拒绝时，本地服务不可用可以使用当前选区 AI 即时翻译；拒绝全文翻译后及全文缓存已经完成后，不自动用新的云端翻译替代本地失败，用户可点击“重新翻译”。

词典和已有译文的返回不等待周边上下文提取；仅真正需要 AI 上下文的请求才等待它。

## 重新翻译与保存边界

重新翻译始终由用户显式点击并调用 AI。

- true：提供完整已存源文及附近上下文，仅重译选区。将选区修订和对应术语写入该论文的翻译文件；若选区是完整已存句子，同时更新该句译文。其他句子不变。
- false：可带附近上下文，但只翻译选区。不创建、更新局部翻译缓存，不设置 true。
- 如全文背景超过所选模型的上下文容量，报告错误，避免静默截断后冒充全文专业化重译。

状态与文件保存在当前 profile 下：

```text
zaibar/paper-translations/<libraryID>-<attachmentKey>-<language>/
  state.json
  translation.json
```

`state.json` 保存 translated、用户选择、后台进度和错误。`translation.json` 包含原文—译文分句、全文译文、专业术语、选区修订。全文内容和元数据使用临时文件原子替换；相关写操作串行化。日常查询复用内存状态和有界文件缓存，不每次重新提取全文。

## 轻量离线资源

- 词典：[ECDICT](https://github.com/skywind3000/ECDICT)，本次实际索引 **770,611 条**、1037 个分片，约 40 MiB 磁盘，MIT 许可证已保存。
- 专用翻译模型：Helsinki-NLP OPUS-MT 英译中模型的 CTranslate2 INT8 转换版。固定转换仓库 revision `d45e5f86313be8e29629dda5f01ec98eba26e947`，权重下载后检查 SHA256。
- [转换模型](https://huggingface.co/manancode/opus-mt-en-zh-ctranslate2-android) 的数据可用于 Windows CTranslate2；Android 名称不代表需要 Android 运行时。
- 模型、分词器、词表、说明和许可证合计 **82,498,061 字节**。上游模型 Apache-2.0 声明及完整许可证已保存。
- 运行时为独立 Python 环境 + CTranslate2 + SentencePiece；不依赖 PyTorch、Ollama 或 GPU。不加载本机 Qwen 3B。
- CPU 两线程、请求串行推理、按需启动。空闲 90 秒后整个服务进程退出，下次需要时重新启动。
- 本机样例首次请求约 **0.337 秒**，推理服务工作集及峰值约 **140.8 MiB**；仅代表该样例和本机，非通用吞吐保证。验证空闲自动退出时使用了缩短的 5 秒测试配置。
- Python 环境约 135 MiB，词典约 40 MiB，模型约 79 MiB，离线资源合计约 254 MiB 磁盘。
- 离线句子模型当前支持英译中（简体／繁体）；词典释义为简体中文。论文专业术语由论文缓存和 AI 重译补充，小模型结果明确标注为“基础译文”。

模型运行目录位于源码目录 `.local-runtime/`，已从 Git 排除。profile 保存运行时路径、服务脚本、访问令牌及词典；源码目录和 `.local-runtime/` 应保留，删除或移动后需重新配置路径。模型与词典不塞进 XPI。
