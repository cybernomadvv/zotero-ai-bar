### 会话及模式的区别

文章速答按阅读器文献分配会话，能够附加当前划词。全局助理使用跨阅读器共享会话，不自动绑定当前文献或划词，固定 Agent 模式，可按需读取文库所选文献。文章速答中的普通模式不自动附加全文；全文模式附加正文（过长时提示切换 Agent、使用部分文档快照或取消）；Agent 模式用工具按需搜索和读取。

## 插件内 Skill 模块与解释偏好学习

- Skill 管理入口位于插件设置，支持用户新增、编辑、启停及删除自定义技能；内置解释偏好学习可停用，核心指令不可覆盖或删除。技能是提示指令，不执行脚本。
- 插件问答提供 `manage_skill` 与 `learn_explanation_preference`，快捷/全文模式仅增加 Skill 工具，不因此获得 Agent 的文库写入工具；专门翻译流程不参与学习。Codex 与普通 API 复用相同处理器。
- 首次明确纠正记为 L0，独立重复升至 L3；同场景同维度冲突使旧值降一级并暂停，新值 L0。场景隔离、本轮要求优先、临时要求不持久化。Retry 复用原消息事件 ID，防止重复强化；学习工具要求来源短句属于原始用户输入，不接受选区或历史内容冒充当前反馈。
- 数据位于当前 Zotero profile 的 `zaibar/skills-v1.json`。变更串行、原子写入，写盘成功后才更新内存；写入失败向调用方报错，未知格式与损坏数据不被覆盖。内置指令升级时保留偏好及启停状态。
- 验证：构建和 TypeScript、涉及文件 ESLint、16 项状态回归通过；`node scripts/verify-skills.mjs` 验证工具、原生 JSON 持久化适配、故障不生效与重开恢复。
- `node scripts/verify-skills-zotero.mjs` 在隔离 Zotero 中通过实际 SDK 工具循环：首次 L0、重复 L1、重生成不强化、冲突降级、助手创建技能及上下文注入；真实管理窗口通过创建、编辑、启停、删除、内置保护、忘记偏好与重开。已检查 `.scaffold/skills-native.png` 原生窗口截图。
